# Task 2: Interactive Portfolio Website
A personal portfolio built with plain HTML, CSS and JavaScript.

## Features
- Sections: Home, About, Selected work, Skills, Journey and achievements, Contact
- Smooth navigation with active-section highlighting, scroll progress bar and a mobile menu
- Interactive UI: rotating role text, tilting ID badge, custom cursor ring, scroll reveal animations, animated counters, light and dark themes
- Project showcase with stacking cards, technology filters and a case-study pop-up for each project
- Skills section where each skill filters the projects that use it
- Contact form with live validation, character counter and a mailto hand-off
- Responsive, centred mobile layout, keyboard and screen-reader friendly, reduced-motion support
